## 工程约定

- 代码、冻结配置、来源清单、依赖锁文件、正式文档与精简证据进入版本管理
- 本机任务接力、数据下载、模型、环境、运行结果单独存储；必要知识不得只保存在个人任务文档
- 新运行通过--run-dir独占新目录，worker与报告共享该目录；不覆盖旧成绩，不隐式续跑
- 运行保存输入哈希、参考快照、参数、版本、原始结果与退出记录；下载、初始化、预热、推理分开
- 轻量回归先验证逻辑边界，少量真实推理验证整条链路；完整评测只在影响结果时重跑
- 识字、阅读顺序、表格、公式按目标分别评价；候选发现、链路跑通、质量达标不是同一结论
- 参考和指标先确定，再看模型输出；任何修改都另建版本并保留旧证据
- 第三方技能、参考项目源码、客户数据与密钥不随本项目复制

当前尚未初始化Git、配置远端或CI；文档和忽略规则已经整理好，不能把它们等同于已经提交或发布
