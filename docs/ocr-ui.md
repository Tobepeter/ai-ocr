# 本地 OCR 对比页

参考ai-voice的Gradio页面与隔离worker结构：同一输入、逐个引擎、结果并列、逐步显示状态并保存原始输出。参考源码只读，未复制其模型环境

参考文件：ai-voice的src/ai_voice/web/app.py与worker.py；只用于设计借鉴，客户无需获取参考工程

## 启动

```sh
./scripts/ocr-ui.sh
# 改端口
./scripts/ocr-ui.sh --port 7862
```

默认地址http://127.0.0.1:7861，仅本机访问，不启用公网分享。服务前台运行，Ctrl+C停止

使用已安装MinerU工具环境里的Gradio，不增加项目模型依赖；轻量项目环境先`uv sync`，供CER计算使用。引擎worker分别调用用户级RapidOCR、MinerU、Docling；Apple Vision首次用swiftc编译项目源文件，产物留在.temp中

## 默认示例

预置20份示例：2份随Git保存的自制图片，另18份研究物料（14份中文/混排、4份英文），覆盖课件、论文、书页、彩色教材、试卷、报纸、简繁体报告、表单、街景、招牌行及旧扫描。名单在configs/ui-examples.json，不重复下载或复制图片

点击示例只载入图片，不自动跑模型；同时清空上一张的参考文本，避免误用参考计分。全新副本至少有2份自制示例；缺失研究图片自动隐藏并提示，可按[复现指南](reproduce.md)补齐

## 使用与指标

上传或粘贴一张图片，选择参与对比的方案，可选填写完整人工参考文字，点击开始。默认四种方案并行识别，完成一项就显示一项；可切换顺序模式用于测速。统一旋转方向、RGB、长边最多2000像素；暂不支持直接上传PDF或多文件批测

结果包含文本/Markdown、总耗时、初始化和处理时间、可选CER。没有参考就不显示准确率。CER v3按NFC字素计算Levenshtein编辑距离，忽略空白，保留大小写、标点、全半角及简繁。MinerU/Docling从结构化节点提取正文，生成的Markdown和图片编码不再计错；真正正文符号仍保留。参考必须完整、顺序一致，失败按空输出计漏字；无完整参考不计分。公式/表格/阅读顺序能力应另测，参见[评价协议](ocr-evaluation-v3.md)。CER可以超过100%，不转换成“100%-CER正确率”

每次引擎独立进程启动；并行时最多4项同时运行，同一时刻只处理一组请求。并行耗时受资源争抢影响，不将各引擎耗时相加当作整组等待时间。报告保存execution_mode、整组elapsed_seconds及各项起止偏移，便于区分运行口径；处理时间可能包含延迟加载，Apple首次总时间含编译，与历史常驻热推理成绩分开。单引擎240秒超时，失败项保留，其他引擎继续。此页不宣称是完整内存基准

输入、人工参考、日志和原始结果保存在`data/outputs/ocr-ui/{时间-标识}/`，`comparison.json`可从页面下载。输出为本地数据，不写入Git；显示/评分剥离内嵌图片编码，原始引擎文件保留
